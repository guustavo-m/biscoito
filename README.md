# Biscoito da Sorte

Aplicativo mobile desenvolvido com React Native + Expo para gerar frases motivacionais ao clicar em um biscoito virtual. O projeto simula a experiência de um biscoito da sorte, com animações, contador de uso, frase favorita e efeitos sonoros.

## 📱 Sobre o projeto

Este app foi criado como uma aplicação interativa divertida e inspiradora, voltada para apresentar mensagens de incentivo e motivação. A interface foi pensada para ser simples, colorida e responsiva em dispositivos móveis.

## ✨ Funcionalidades

- Sorteio aleatório de frases motivacionais;
- Animação ao abrir e quebrar o biscoito;
- Contador de biscoitos quebrados;
- Exibição da última frase sorteada;
- Opção para marcar uma frase como favorita;
- Efeito sonoro ao abrir o biscoito;
- Visual com cores dinâmica e layout amigável.

## 🛠️ Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- Expo Audio
- SVG assets locais

## ▶️ Como executar

1. Abra o terminal na pasta do projeto.
2. Instale as dependências:

```bash
npm install
```

3. Inicie o aplicativo:

```bash
npm start
```

4. Em seguida, escolha uma opção para abrir no emulador ou no navegador:

```bash
npm run android
npm run ios
npm run web
```
